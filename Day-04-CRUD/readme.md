## CRUD Operation

Create/Insert, Read/Retrieve, Update, Delete
## item
    -id, name, price, qty
## Features: 
    -1. Add to Cart
    -2. Show Cart
    -3. Remove from cart
    -4. Update quantity from cart
    -5. Checkout

    NOTE: all items will be strored in harddisk(hdd), so after termination of program we can retrieve cart details

## Required files: 
    -crud.js - it contains all the methods and entry point
    -products.json - it contains the product details in array form [JSON- javascript object notation] (array of objects/items)
